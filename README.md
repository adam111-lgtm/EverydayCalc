#EverydayCalc

EverydayCalc is a clean, minimal web application designed for quick, hassle-free daily calculations—from quick tips and unit conversions to basic arithmetic.

Key Features
Quick Conversions: Instant switching between units (length, weight, temperature).

Smart History: Saves your recent calculations locally so you never lose track.

Responsive Layout: Works smoothly on desktop, tablet, and mobile browsers.

Dark/Light Mode: Automatically adapts to system preferences or manual toggles.
Tech Stack
Structure: HTML5

Styling: CSS3 (Flexbox & Grid)

Logic: Vanilla JavaScript

Typography: Google Fonts

Icons: Font Awesome v6
